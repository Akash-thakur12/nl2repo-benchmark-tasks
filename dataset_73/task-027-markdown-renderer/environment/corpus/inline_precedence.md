# Inline precedence

Use `**not bold**` here.

Write `[a](b)` literally.

A pipe inside code: `a|b` stays one token.

| Expr | Meaning |
| --- | --- |
| `a|b` | bitwise or |
| `x \| y` | escaped pipe |

- a list item with `__dunder__` and `*stars*` inside code
- and one with **real bold** outside code
